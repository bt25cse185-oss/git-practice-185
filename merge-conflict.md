
# Merge Conflict Report

## Introduction
A merge conflict occurs when Git cannot automatically combine
conflicting changes made to a file.

## Conflict Details
File involved: To be recorded during the exercise.

Cause: Conflicting edits made on different branches.

## Resolution Steps
1. Inspect the conflicting file.
2. Review the conflict markers.
3. Choose or combine the correct changes.
4. Remove the conflict markers.
5. Save, stage, and commit the resolved file.

## Result
Record the actual conflict and its resolution after completing
the merge-conflict exercise.
